Customizer Core

Everything Customizer Core does, on one page

Customizer Core is a Laravel + Inertia + Vue 3 app. Reps, dealers and customers use it to design uniforms, build carts, get quotes and approvals, and place and track factory orders. The Prolook/QStrike API is the system of record for accounts, saved designs and orders. Click any screen, builder tab or flow to see its routes and code.

How a builder session works

  1. The page loads the uniform as normal, saved-design, cart-item or reorder-item (customizerStore.initialize*).
  2. @qstrike/builder draws the uniform on a PIXI canvas (core/stage/stage.ts) in 2D layers, or as 3D trim shapes.
  3. Each edit updates the 10k-line stores/customizer.js. Undo/redo keeps 50 snapshots (reskin only).
  4. Thumbnails for each view are captured from the canvas and uploaded to S3 through /api/image/upload.
  5. Save goes straight to Prolook (/saved_design). Add to Cart runs these checks, then POST /carts/items:
    • a team is chosen;
    • the minimum team colors are set;
    • logo colors don't conflict;
    • a brand logo color is chosen;
    • sizes and the roster are valid.

Architecture

Every page request goes through Laravel and Inertia. Heavy work runs in job chains: thumbnails, then PDF, then analytics. Live updates use Pusher broadcasts. Partner systems call in through key-protected APIs.

Data model

A user owns carts and a cart holds items. Submitting a cart creates one order. Team stores are a separate set of tables with their own carts and orders.
