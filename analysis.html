How it works

  1. You submit the request. It is emailed to the BRD owner and marked Pending.
  2. The BRD analyst reviews the document on its own — it does not look at the Customizer code.
  3. You receive the analysis report by email; the request becomes Completed.
  4. The team develops the change and updates the Customizer repository manually.
  5. The audit agents then check the repository and report whether each requirement is implemented, partially implemented or not implemented.
